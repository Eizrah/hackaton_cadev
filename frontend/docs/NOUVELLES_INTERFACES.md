# Documentation des interfaces

La version du **5 novembre 2026** ajoute les parcours JavaScript et React dans une salle de cours partagée avec HTML5 & CSS3. Consulte `APPRENTISSAGE_WEB.md` pour les niveaux, les leçons, les projets et l’atelier. Les autres interfaces suivent les directives du **31 octobre 2026**. Lire `DIRECTIVES_31_OCTOBRE.md` pour le détail et `CHANGEMENTS.md` pour les fichiers concernés.

Cette version remplace la notation 1–5 par une étoile d’appréciation, fusionne question/découverte, retire le parcours Fullstack, ajoute le suivi des candidatures, les deux interfaces d’agents, la langue FR/EN et la nouvelle messagerie.

Les choix précédents conservés sont la carte de profil translucide avec édition séparée, le portfolio facultatif, les icônes de compétences, les drapeaux, les dates et le catalogue Web, Mobile et Langages de programmation.
