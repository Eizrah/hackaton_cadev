========================================
  LISTE DES APIs - CADEV BACKEND
========================================

Base URL : http://localhost:8000

Pour les endpoints qui requièrent une authentification,
ajouter dans le header de la requête :
  Authorization: Bearer <access_token>

Les tokens JWT ont une durée de vie de :
  - Access token  : 30 minutes
  - Refresh token : 7 jours

========================================
  AUTHENTIFICATION  (/api/auth/)
========================================

POST   /api/auth/inscription/
  → Créer un nouveau compte développeur
  → Type : Multipart Form (si photo) ou JSON (sans photo)
  → Body : {
        "email": "dev@example.com",
        "nom": "Rakoto",
        "prenom": "Jean",           (optionnel)
        "pseudo": "rakoto_dev",
        "age": 25,
        "niveau": "D/I/A",
        "pays": "Madagascar",
        "sexe": "M/F",
        "password": "motdepasse123",
        "password_confirm": "motdepasse123",
        "photoprofil": [fichier],   (optionnel)
        "experiences": [            (optionnel)
            {
                "nom_poste": "Développeur Frontend",
                "description": "Développement React",
                "nbr_annee_exp": 2,
                "diplome": "Licence Informatique",
                "certificat": null,
                "fichier_diplome": [fichier PDF/DOCX/JPEG/PNG],
                "fichier_certificat": [fichier PDF/DOCX/JPEG/PNG]
            }
        ],
        "competences": [            (optionnel — UUIDs des compétences possédées)
            "uuid-competence-1"
        ]
    }
  → Rate limit : 5 tentatives/heure par IP

POST   /api/auth/connexion/
  → Se connecter et récupérer les tokens JWT
  → Body : { "email": "dev@example.com", "password": "motdepasse123" }
  → Rate limit : 10 tentatives/heure par IP

POST   /api/auth/deconnexion/
  → Se déconnecter et invalider le refresh token
  → Requiert : token JWT
  → Body : { "refresh": "<refresh_token>" }

GET    /api/auth/profil/
  → Récupérer les infos du développeur connecté
  → Requiert : token JWT

PUT    /api/auth/profil/
  → Modifier les infos du développeur connecté (partiel)
  → Requiert : token JWT
  → Type : Multipart Form (si photo) ou JSON

DELETE /api/auth/supprimer-compte/
  → Supprimer son compte et sa photo de profil
  → Requiert : token JWT
  → Body (optionnel) : { "refresh": "<refresh_token>" }

GET    /api/auth/recherche/?q=<mot_cle>
  → Rechercher un développeur par pseudo, nom ou prénom
  → Requiert : token JWT

POST   /api/auth/mot-de-passe-oublie/
  → Envoyer un email de réinitialisation
  → Body : { "email": "dev@example.com" }
  → Rate limit : 3 tentatives/heure par IP

POST   /api/auth/reinitialisation-mot-de-passe/<uidb64>/<token>/
  → Réinitialiser le mot de passe via le lien reçu par email
  → Body : { "password": "nouveaumotdepasse123" }

========================================
  FORUM  (/api/forum/)
========================================

GET    /api/forum/posts/
  → Liste des posts validés (feu_vert=True), du plus récent au plus ancien
  → Requiert : token JWT (exclut les posts des devs bloqués)

POST   /api/forum/posts/creer/
  → Créer un post — l'IA valide automatiquement le contenu
  → Requiert : token JWT
  → Type : Multipart Form (si fichier) ou JSON
  → Body : {
        "description": "Contenu du post...",
        "fichier": [fichier max 20Mo],  (optionnel)
        "lien": "https://..."           (optionnel)
    }
  → Réponse si approuvé  : HTTP 201 + { "message": "Post créé et validé.", "post": {...} }
  → Réponse si refusé    : HTTP 400 + { "message": "...", "raison": "...", "feu_vert": false, "post": {...} }
  → Réponse si IA indispo : HTTP 201 + { "message": "En attente de validation.", "post": {...} }

GET    /api/forum/posts/recherche/?q=<mot_cle>
  → Rechercher un post par mots clés
  → Requiert : token JWT

GET    /api/forum/posts/<id>/
  → Détail d'un post validé
  → Requiert : token JWT

PUT    /api/forum/posts/<id>/
  → Modifier son post (repassera en validation IA)
  → Requiert : token JWT + être le créateur

DELETE /api/forum/posts/<id>/supprimer/
  → Supprimer son post
  → Requiert : token JWT + être le créateur

GET    /api/forum/posts/<id>/commentaires/
  → Liste des commentaires d'un post
  → Requiert : token JWT

POST   /api/forum/posts/<id>/commentaires/
  → Ajouter un commentaire (ou répondre à un commentaire)
  → Requiert : token JWT
  → Body : {
        "commentaire": "Super post !",
        "commentaire_parent": "<uuid>"  (optionnel — pour répondre)
    }

PUT    /api/forum/posts/<id>/commentaires/<id_commentaire>/
  → Modifier son commentaire
  → Requiert : token JWT + être le créateur

DELETE /api/forum/posts/<id>/commentaires/<id_commentaire>/
  → Supprimer son commentaire
  → Requiert : token JWT + être le créateur

POST   /api/forum/posts/<id>/noter/
  → Liker ou unliker un post (toggle automatique)
  → Requiert : token JWT
  → Pas de body nécessaire

GET    /api/forum/enregistrements/
  → Voir ses publications enregistrées (posts + offres)
  → Requiert : token JWT

POST   /api/forum/enregistrements/
  → Enregistrer un post ou une offre
  → Requiert : token JWT
  → Body : {
        "type_publication": "forum_post" ou "offre_emploi",
        "id_publication": "<uuid>"
    }

DELETE /api/forum/enregistrements/<id>/supprimer/
  → Retirer un enregistrement
  → Requiert : token JWT

        "lien": "https://..."       (optionnel)
    }
  → Réponse si approuvé  : HTTP 201
  → Réponse si refusé    : HTTP 400 + { "raison": "...", "feu_vert": false, "offre": {...} }

GET    /api/jobs/offres/recherche/?q=<mot_cle>

========================================
  MODÉRATION  (/api/moderation/)
========================================

POST   /api/moderation/signaler/dev/<email>/
  → Signaler un développeur
  → Requiert : token JWT
  → Body : { "motif": "Harcèlement ou intimidation" }

POST   /api/moderation/signaler/post/<id>/
  → Signaler un post du forum
  → Requiert : token JWT
  → Body : { "motif": "Contenu inapproprié" }

POST   /api/moderation/signaler/offre/<id>/
  → Signaler une offre d'emploi
  → Requiert : token JWT
  → Body : { "motif": "Spam ou publicité" }

POST   /api/moderation/signaler/groupe/<id>/
  → Signaler un groupe
  → Requiert : token JWT
  → Body : { "motif": "Discours haineux" }

  Motifs disponibles :
    - Contenu inapproprié
    - Spam ou publicité
    - Harcèlement ou intimidation
    - Discours haineux
    - Informations fausses ou trompeuses
    - Violation de droits d'auteur
    - Contenu dangereux
    - Autre (précisez)

  Seuils de pénalité :
    - Dev    : banni à 10 points
    - Post   : supprimé (feu_vert=False) à 7 points
    - Offre  : supprimée (feu_vert=False) à 7 points
    - Groupe : désactivé à 7 points

========================================
  AGENTS IA — RÉSUMÉ
========================================

  Deux agents sont intégrés :

  1. Agent Vérification (automatique)
     - Vérifie les posts, offres et commentaires avant publication
     - Utilise Groq (llm : openai/gpt-oss-20b) avec fallback OpenRouter
     - Résultat : feu_vert=True (approuvé) ou False (refusé + notif)

  2. Agent Assistant pédagogique
     - Répond aux questions techniques informatiques uniquement
     - Utilise le RAG (doc officielle via ChromaDB + HuggingFace embeddings)
     - Garde l'historique dans les sessions (/api/messaging/sessions/)
     - Adapte ses réponses au niveau du dev (D/I/A)
